# 02 - Bases & Kanban Boards

Zuber includes native support for **`.base` files** (Obsidian Bases-compatible YAML definitions) rendered as interactive **1D Kanban Boards**, **2D Swimlane Matrices**, and **Filtered Tables**.

> [!TIP] Interactive Drag & Drop
> Dragging a card between columns or swimlanes automatically updates the underlying note's YAML frontmatter (`status`, `prio`, etc.) on disk!

## Included Demo Bases

1. **[[Project-Board.base]]** — 1D Kanban board grouped by `status` (`Open`, `In Progress`, `Review`, `Done`).
2. **[[Priority-Matrix-2D.base]]** — 2D Swimlane Kanban board grouped by `status` (columns) and `prio` (rows).
3. **[[Hardware-Inventory.base]]** — Filterable table view displaying infrastructure & device notes.

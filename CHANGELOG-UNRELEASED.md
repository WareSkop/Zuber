### Added
- **Compact/Preview File Nodes in Canvas (`CanvasFileNode`, `CanvasInspector`, `canvasMapper`):** Newly added `.md` and `.pdf` file nodes now default to a sleek single-row compact placeholder (`displayMode: 'card'`, `220×58`, quick-open `↗`, color tinting, no scrollbars) with a 1-click `[Card | Preview]` toggle in `CanvasInspector` / node context menu that remembers custom `previewWidth` / `previewHeight` dimensions across toggles and renders embedded PDF previews via `<iframe>` alongside scrollable Markdown previews.
- **Multi-Source Canvas Drag & Drop, Direct Note Creation & Settings (`CanvasEditor`, `CanvasToolbar`, `FileSidebar`):** Added drag-and-drop from `FileSidebar` (`application/x-zuber-file`) onto canvas coordinates, direct OS image and PDF drag-and-drop upload into the canvas companion folder, `+ New Note` toolbar action + canvas pane right-click context menu (`<dialog>` prompt), and a Canvas Settings popover to inspect, customize, or reset `assetsFolder`.
- **Canvas Companion Folders & Virtual Tree Expansion (`VaultService`, `canvasTreeUtils`, `FileSidebar`):** Added lazy `<CanvasName>.canvas.assets/` companion folders that are hidden as standalone folders and surfaced directly beneath expandable `.canvas` rows (physical companion files, linked external vault files, and canvas external URLs), paired with strict `.canvas` directory vs. file safety and atomic companion directory synchronization in `VaultService.renameOrMove()` and `moveBatch()`.
- **Global External Links Sidebar Section (`VaultService`, `/api/vault/external-links`, `FileSidebar`):** Added a collapsible "External Links" / "Externe Links" section in the left sidebar aggregating vault-wide `http(s)://` URLs from Markdown notes and `.canvas` files with live filtering, expandable source note chips, and Research Split / Ctrl+Click routing.
